2. Principio di base

NomBon non richiede un account. Non c’è pubblicità, né tracciamento, né strumenti di analisi, né vendita di dati.

3. I tuoi acquisti restano sul tuo dispositivo

NomBon salva gli scontrini riconosciuti (negozio, data, articoli, prezzi, valori nutrizionali stimati) e le impostazioni della tua famiglia solo in locale sul tuo telefono. Noi non vi abbiamo accesso. Se elimini uno scontrino o l’app, i dati vengono cancellati. A seconda delle impostazioni del telefono, possono essere inclusi nel tuo backup del dispositivo (iCloud o Google).

4. Lettura degli scontrini

Quando fotografi uno scontrino, scegli una foto o importi uno scontrino elettronico (PDF), l’immagine o il file viene inviato in forma cifrata al nostro server e lì letto da un’IA. Il risultato (l’elenco degli articoli) torna sul tuo telefono. La foto o il file non viene salvato da noi. Sugli scontrini possono comparire dati come il metodo di pagamento, parti del numero di una carta o numeri cliente di carte fedeltà; questi non vengono analizzati né salvati.

Base giuridica: art. 6, par. 1, lett. b GDPR (usi la funzione per far leggere il tuo scontrino).

Dizionario delle abbreviazioni

Per riconoscere meglio le abbreviazioni sugli scontrini (ad es. «LakFr H-Milch»), il nostro server memorizza per le singole righe di articolo solo: la catena, il testo della riga senza il prezzo e il nome del prodotto riconosciuto con la categoria. Non vengono salvati foto, prezzi, data, ora, punto vendita, dati di pagamento né quali articoli hai acquistato insieme. Le righe sconosciute vengono fatte interpretare una sola volta da un’IA, esclusivamente come testo.

Se correggi il nome di un prodotto nell’app, il tuo telefono memorizza la correzione. Inoltre viene inviata al server senza alcun riferimento personale (catena, testo della riga, nome del prodotto, categoria e un identificatore casuale dell’installazione della tua app, in modo che una correzione conti una sola volta). Solo quando più installazioni correggono la stessa cosa, la correzione vale per tutti. Le righe con numeri cliente o di carta non vengono mai recepite. Le voci che non compaiono da 18 mesi vengono eliminate.

Base giuridica: art. 6, par. 1, lett. f GDPR (legittimo interesse a un riconoscimento migliore; i dati non permettono di risalire a te).
