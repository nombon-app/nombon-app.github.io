2. Grundsatz

NomBon braucht kein Konto. Es gibt keine Werbung, kein Tracking, keine Analyse-Werkzeuge und keinen Verkauf von Daten.

3. Deine Einkäufe bleiben auf deinem Gerät

Die erkannten Bons (Laden, Datum, Artikel, Preise, geschätzte Nährwerte) und deine Haushalts-Einstellungen speichert NomBon nur lokal auf deinem Handy. Wir haben keinen Zugriff darauf. Löschst du einen Bon oder die App, sind die Daten weg. Je nach Einstellung deines Handys können sie in deiner eigenen Geräte-Sicherung (iCloud bzw. Google) enthalten sein.

4. Auslesen der Bons

Wenn du einen Bon fotografierst, ein Foto auswählst oder einen eBon (PDF) importierst, wird dieses Bild bzw. diese Datei verschlüsselt an unseren Server geschickt und dort von einer KI ausgelesen. Das Ergebnis (die Artikelliste) geht an dein Handy zurück. Das Foto bzw. die Datei wird bei uns nicht gespeichert. Auf Kassenbons können Angaben wie Zahlungsart, Teile einer Kartennummer oder Bonus-Kundennummern stehen; diese werden nicht ausgewertet und nicht gespeichert.

Rechtsgrundlage: Art. 6 Abs. 1 lit. b DSGVO (du nutzt die Funktion, um deinen Bon auszulesen).

Kürzel-Wörterbuch

Damit Abkürzungen auf Kassenbons (z. B. „LakFr H-Milch“) besser erkannt werden, merkt sich unser Server zu einzelnen Artikelzeilen nur: die Handelskette, den Text der Zeile ohne Preis und den erkannten Produktnamen mit Kategorie. Nicht gespeichert werden Fotos, Preise, Datum, Uhrzeit, Filiale, Zahlungsdaten oder welche Artikel du zusammen gekauft hast. Unbekannte Zeilen lässt der Server einmalig – nur als Text – von einer KI auflösen.

Korrigierst du in der App einen Produktnamen, merkt sich dein Handy die Korrektur. Zusätzlich wird sie ohne Personenbezug an den Server geschickt (Kette, Zeilentext, Produktname, Kategorie und eine zufällige Kennung deiner App-Installation, damit eine Korrektur nur einmal zählt). Erst wenn mehrere Installationen dasselbe korrigieren, wirkt sie für alle. Zeilen mit Kunden- oder Kartennummern werden nie übernommen. Einträge, die 18 Monate nicht mehr vorkamen, werden gelöscht.

Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einer besseren Erkennung; die Daten lassen keinen Rückschluss auf dich zu).
